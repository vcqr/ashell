# AShell 无边框窗口圆角实现方案

> 参考方案：[Tauri 2 跨平台圆角窗口（jishuzhan.net/article/2062848427322585089）](https://jishuzhan.net/article/2062848427322585089)
> 本文记录该方案在 AShell 的完整落地配置与踩坑细节，供后续维护/移植参考。

## 一、原理

Tauri 2 没有原生圆角 API。方案核心是五件事配合：

1. `decorations: false` 去掉系统边框（自绘标题栏）；
2. `transparent: true` 让窗口背景透明；
3. **`shadow: false` 关掉系统阴影**——系统阴影按窗口**矩形**画，WKWebView 的透明内容取不到形状，开着它圆角外必有一圈方形阴影（亮色桌面下尤其明显）；
4. WebView 背景强制全透明（Rust 侧 `set_background_color`），否则 WebView 默认底色会从圆角外四角露出色块；
5. 圆角和投影全部交给 CSS：圆角画在 `body` 上，投影用 `::after` 伪元素承担。

## 二、逐文件配置明细

### 1. `src-tauri/tauri.conf.json`（主窗口）

```jsonc
"macOSPrivateApi": true,     // macOS 透明窗口前提（Windows/Linux 无影响）
"windows": [
  {
    "title": "AShell",
    "maximized": true,
    "visible": false,
    "decorations": false,     // 无边框、自绘标题栏
    "transparent": true,      // 窗口透明，圆角外透出桌面
    "shadow": false,          // ★ 关键：关系统阴影，消除圆角外的方形阴影
    "dragDropEnabled": false  // 与圆角无关，原有配置（HTML5 dnd 需要）
  }
]
```

### 2. `src-tauri/Cargo.toml`

```toml
tauri = { version = "2", features = ["macos-private-api", ...], optional = true }
```

`macos-private-api` feature 是 macOS 透明窗口的前提，与 conf 里的 `macOSPrivateApi: true` 必须同时存在（缺 feature 时构建直接报错）。

### 3. `src-tauri/capabilities/default.json`

需要两项关键权限（其余 `core:default` / `opener:default` 等为应用原有）：

```jsonc
"core:window:allow-start-dragging",                  // 标题栏拖拽
"core:webview:allow-set-webview-background-color"    // WebView 背景色接口
```

注意：应用自有命令（`invoke_handler` 里注册的 `#[tauri::command]`）**不走 ACL**，不需要在 capabilities 里加条目。

### 4. `src-tauri/src/lib.rs`（setup 钩子）

```rust
if let Some(win) = app.get_webview_window("main") {
    // 透明色是 Color(0, 0, 0, 0)，不是 (255, 255, 255, 0)
    let _ = win.set_background_color(Some(tauri::webview::Color(0, 0, 0, 0)));
    ...
}
```

- `Color` 在 `tauri::webview` 模块下（不是 `tauri::Color`）；
- 只对主窗口做即可；独立窗口由 JS 侧 `transparent: true` 创建时生效。

### 5. `src/utils/newWindow.ts`（四类独立窗口）

终端新窗 / SFTP / AI / 主机信息四个 `new WebviewWindow` 的配置与主窗口对齐：

```ts
decorations: false,
transparent: WINDOW_TRANSPARENT, // mac/Win 为 true；Linux 保持不透明直角
shadow: false,                   // 同主窗口，关方形系统阴影
```

`WINDOW_TRANSPARENT = detectMac() || detectWindows()`——Linux 的 GTK 透明窗口兼容性差，独立窗口保持不透明（主窗口不受影响）。

### 6. `src/composables/useWindowRounded.ts`

在 `App.vue` setup 里调用 `initWindowRounded()`（主窗与所有独立窗口共用同一入口）。职责只有一项：**真全屏时摘掉圆角 class**。

```ts
const apply = async () => {
  const fullscreen = await win.isFullscreen()
  document.body.classList.toggle("window-rounded", !fullscreen)
}
await apply()
await win.onResized(() => void apply())
```

- **最大化 / macOS 绿钮缩放 / Win11 贴边分屏都保留圆角**（用户确认与原生应用行为一致）；
- 仅真全屏收回——全屏铺满整屏，CSS 圆角会在屏幕四角露透明缺口。

### 7. `src/assets/main.css`（圆角与阴影本体）

```css
body.window-rounded {
  border-radius: 10px;      /* 定稿 10px（文章原值 16px 偏大）；改这里即可全局调整 */
  /* ★ body 有 transform 即成为 position:fixed 后代的包含块：
     AI 面板 / 停靠抽屉 / naive 弹层等 fixed 悬浮元素原本不受 body 圆角
     裁剪，方角会盖住窗口圆角（典型症状：唯独右下角直角）；
     纳入后统一被圆角裁掉。body 占满视口，fixed 元素几何不变 */
  transform: translateZ(0);
}

/* 阴影伪元素：继承圆角、置于内容层之下（文章原值两段式柔和投影）。
   不能直接在圆角容器上写 box-shadow：阴影会超出圆角范围，
   亮色桌面下形成灰色矩形边框 */
body.window-rounded::after {
  content: "";
  position: absolute;
  inset: 0;
  border-radius: inherit;
  pointer-events: none;
  z-index: -1;
  box-shadow:
    0 8px 32px rgba(0, 0, 0, 0.22),
    0 2px 8px rgba(0, 0, 0, 0.14);
}
```

前提（本项目原有）：`html, body, #app { background: transparent; overflow: hidden; }`。

## 三、踩坑记录

| 症状 | 根因 | 解法 |
| --- | --- | --- |
| 圆角外一圈方形阴影，右下角最明显 | 系统阴影按窗口矩形画，WKWebView 透明内容取不到形状 | conf/独立窗口 `shadow: false` |
| 最大化/启动时四角全方 | 圆角 class 被最大化状态摘掉 | 最大化保留圆角，仅全屏摘（见 useWindowRounded） |
| 唯独右下角直角，其余三角正常 | `position: fixed` 悬浮层（AI 面板贴右侧 `bottom: 0`）不受 body 圆角裁剪，方角盖住窗口角 | body 加 `transform: translateZ(0)`，fixed 后代纳入圆角裁剪 |
| 圆角外露底色 | WebView 默认背景不透明 | lib.rs `set_background_color(Color(0,0,0,0))` |
| 圆角外灰色矩形框 | box-shadow 直接写在圆角容器上，阴影超出圆角 | 阴影移到 `::after`（`border-radius: inherit` + `z-index: -1`） |
| 模态/抽屉遮罩四角溢出 | naive 浮层 Teleport 到 body、`position: fixed` | 由 body 的 transform 包含块机制统一裁剪，无需逐个补圆角 |

## 四、与参考文章的差异（多窗口应用适配）

文章是单窗口 demo，AShell 为多窗口应用，以下为必要适配：

1. 圆角/阴影画在 `body` 层而非单个 `.app-wrapper`——主窗与四类独立窗共用同一套样式；
2. `useWindowRounded` 的全屏摘圆角逻辑（文章 demo 非最大化启动，无此项）；
3. Linux 独立窗口不透明直角（GTK 透明兼容性），主窗口仍透明；
4. 深色模式未引入文章的 `prefers-color-scheme`（AShell 有自己的主题系统）。

## 五、调整指引

- **圆角弧度**：`main.css` 中 `body.window-rounded` 的 `border-radius`（现 10px），阴影伪元素 `border-radius: inherit` 自动跟随；
- **投影浓淡**：`::after` 的 `box-shadow` 两段数值；
- **恢复系统阴影**：把 conf 与 `newWindow.ts` 的 `shadow: false` 去掉即可，但方形阴影会回来，不建议。
