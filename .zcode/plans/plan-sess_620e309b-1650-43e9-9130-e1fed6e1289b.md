## 目标

备份设置新增 **SFTP** 后端，与 S3 / WebDAV 并列第三个标签，完整支持配置、测试连接、立即备份、历史列表、恢复、删除。

## 核心设计

- **配置引用已保存主机**（不复用 sid 连接池、不另存凭证）：`SftpConfig { host_id, path_prefix }` 存入 `backup.json`（`sftp` 对象字段，serde default 向后兼容）。凭证（AES 加密的密码/私钥）、known_hosts TOFU 校验、跳板机全部复用现有 SSH 栈；host_id 悬空（主机已删/换机）时报"请重新选择主机"。
- **每次备份操作新建连接**：`Session::connect`（支持跳板机）→ SFTP channel → 操作完显式 `disconnect`。备份低频，符合现有模式。
- `backend` 参数扩展 `"sftp"`，前端标签组第三个 pane，操作/历史区继续共享。

## 后端（src-tauri）

1. **新文件 `service/sftp_backup.rs`**（注册进 `service/mod.rs`）：
   - `SftpConfig { host_id: i64, path_prefix }`。
   - `SftpStorage::connect(pool, crypto_key, cfg)`：`host::get_with_credentials` → `Session::connect`（自动 TOFU/跳板机）→ open SFTP channel（`channel_open_session` + `request_subsystem("sftp")` + `SftpSession::new`，复刻 ssh.rs:630-648 三步）。
   - `put`（先按 prefix 逐级 mkdir，try_exists+create_dir，AtomicBool 标志每实例一次 → `sftp.create` + write_all）、`get`（NoSuchFile 错误 → None）、`delete`（NoSuchFile → Ok）、`disconnect`。
   - `#[ignore]` live 往返测试（连 127.0.0.1:22，环境无 sshd 则以单测+编译为准）。
2. **`service/backup.rs`**：
   - `BackupConfig` 加 `#[serde(default)] sftp: Option<SftpConfig>`。
   - `Storage` 加 `Sftp` 变体；`create_storage` 签名改为 `(pool, crypto_key, cfg, backend)`（SFTP 认证需解密凭证）；新增 `Storage::shutdown()`（SFTP 断开，其余 no-op），5 个 op 函数结尾调用。
   - `path_prefix_for` 加 sftp 分支；`test_connection`/`list_backups`/`delete_backup` 签名补 `pool, crypto_key`（create/restore 已有）；空配置检查加 sftp 分支（host_id 无效 → 报错/空列表）。
3. **`handlers/backup.rs`**：`SaveConfigInput`/`TestInput` 加 `sftp` 字段；各 handler 传 `s.db`/`crypto_key`。
4. 未信任主机 → `AppError::HostKeyVerify` 直接透传错误（含指纹），用户先在主机列表连接一次完成信任后重试（首版不在备份页内嵌确认弹窗）。

## 前端（src/）

1. **`src/api/backup.ts`**：`BackupBackend` 加 `"sftp"`；新增 `SftpConfig { host_id, path_prefix }`；`SaveConfigInput`/`BackupConfig` 加 `sftp`。
2. **`BackupSection.vue`**：第三个 NTabPane（SFTP）：NSelect 主机下拉（`useHostStore`，过滤 `protocol === "ssh"`，label 同跳板机先例 `name (username@addr)`，onMounted 确保已加载）+ 存储目录输入；`buildPayload` 加 sftp；操作函数无需改（跟随 activeBackend）。
3. **locale**：`providerSftp`、`sftpHost`、`sftpHint`（凭证/主机密钥校验/跳板机复用主机配置）、`sftpHostRequired`、`sftpHostMissing`（主机已删除）。
