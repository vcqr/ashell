## 主机卡片视图设计方案

### 效果
主机抽屉新增第三种视图"卡片":所有主机(忽略目录、置顶在前、按现有排序模式)排成自适应网格,抽屉拉宽时自动增列(`auto-fill`,默认 320px 宽约 2 列)。交互与树形一致:单击选中、双击连接、中键新会话、右键菜单、批量勾选、Esc 级联清理。

### 1. 视图状态改造(HostTree.vue script)
- `flatMode: ref<boolean>` 升级为 `viewMode: ref<'tree' | 'flat' | 'card'>`,新 localStorage key `ashell:hosts-view-mode`;读取时兼容旧 key `ashell:hosts-flat === 'true'` → 初始为 `'flat'`。
- 现 `flatMode` 引用点语义变为"非树形视图":`displayData`(flat/card 都用 `flatTreeData`,置顶+排序现成)、`filteredDisplayData` 过滤分支、拖拽禁用、展开全部按钮禁用——统一改为 `viewMode !== 'tree'` 派生,逻辑不变。

### 2. 切换按钮 → 弹出菜单三选一(template)
- 搜索框 suffix 的平铺切换按钮改为 NDropdown(trigger=click):三选项 树形(GitNetworkOutline)/ 平铺(ListOutline)/ 卡片(GridOutline),当前项打勾(CheckmarkOutline,与右键"排序"子菜单同款式);按钮图标随当前视图变化,非树形时 type="primary"。

### 3. 新组件 `src/components/host/HostCardGrid.vue` — 图标与颜色的用法定调
- props:`hosts: HostNode[]`、`selectedKeys`、`checkedKeys`、`batchMode`、`filter`;emits:`select`、`open`(双击)、`open-new`(中键)、`menu`(右键坐标)、`toggle-check`。
- 网格 `repeat(auto-fill, minmax(140px, 1fr))` + 8px 间距;卡片底 `--ashell-panel-bg-soft` + 边 `--ashell-border-soft` + 10px 圆角(参照 HostInfoDrawer 的 `.card`),全走 CSS 变量适配深浅主题。
- **自定义图标 + 用户色是卡片的视觉主载体**:
  - 卡片左侧 34px 圆角**头像块**:背景 = 用户色 14% 透明度淡色底(如 `${color}24`),内放自定义图标 22px(img,比树形视图的 16px 更清晰)或无图标时的 TerminalOutline 着色;
  - 无自定义色时头像块退回默认紫 `#7c5cff`(与树形视图兜底一致);
  - 置顶图钉(PushpinFilled)卡片右上角;批量模式该位置换 NCheckbox(click.stop),勾选卡片主色描边。
- 卡片文本区两行:名称 13px(搜索命中高亮)+ 地址行 12px muted(`addr`,非 22 附 `:port`,serial 只显地址),非 SSH 协议追加小徽标;desc 走原生 title 提示。
- hover/选中/勾选等**交互态统一用主色系**(不混用用户色),用户色只承担身份标识,避免彩色状态打架。
- 卡片 `tabindex=0`,焦点态可见;事件冒泡给 HostTree 复用现有 `showCtxMenu`/`emit("open-host")` 管线(key 约定 `host-{id}` 不变,ctxMenuOptions、findNode 免改)。

### 4. HostTree.vue 接线(template + 少量 script)
- tree-body 内 `<HostCardGrid v-else-if="viewMode === 'card'">`,NTree 改 `v-else`;空态/无匹配 NEmpty 条件不动。
- 卡片 select → `selectedKeys = [key]`;menu → `showCtxMenu(key, x, y)`;toggle-check → checkedKeys 增删;批量条/全选逻辑零改动。
- `onTreeKeydown` 绑定在 tree-body 上继续生效;`onSearchEsc` 回落焦点查询补充 `.host-card-grid` 分支。

### 5. 共享函数抽取
- `splitHighlightSegments`(搜索高亮)与 `suffixTextOfNode` 的地址格式化分支抽到 `src/utils/hosts-view.ts`,HostTree 与卡片组件共用。

### 6. i18n(zh-CN / en-US 的 hosts.ts)
- `hosts.tree.cardView`:"卡片显示" / "Card view";`hosts.tree.viewMode`:"视图" / "View"。
